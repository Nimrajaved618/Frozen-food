# Frost & Fork

A responsive, static frozen-food ecommerce demo built for GitHub Pages from the provided project specifications.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server
```

## GitHub Pages
In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. This is a static site and requires no build step.

The site includes a responsive home/shop experience, category filters, mock product cards, cart count persistence, newsletter validation, accessible labels, semantic sections, and mobile navigation. Product and brand content is demo content and should be replaced before production.
